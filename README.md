# Dados do SUS em R

Códigos curtos e reprodutíveis em R que acompanham os posts de epidemiologia de **Luiz Henrique Arroyo** ([InfoSaúde Estratégica](https://www.linkedin.com/in/luizhenriquearroyo/)) no LinkedIn.

Cada pasta reproduz os números e os gráficos de um post, a partir de dados públicos.

| Pasta | Post | Dados |
| --- | --- | --- |
| [01-padronizacao-de-taxas](01-padronizacao-de-taxas) | Taxa bruta x taxa padronizada (12/11/2026) | Exemplo hipotético |
| [02-prematuridade-sinasc](02-prematuridade-sinasc) | Prematuridade por UF, Brasil 2024 (17/11/2026) | Sinasc, dados finais de 2024 |

## Como usar

1. Instale o [R](https://cran.r-project.org/) e, se quiser, o [RStudio](https://posit.co/download/rstudio-desktop/).
2. Baixe o repositório (botão **Code > Download ZIP**) e descompacte.
3. Abra o script da pasta que interessa e rode a partir da própria pasta.

## Princípios

- Somente dados públicos e agregados, sempre com fonte e data de extração.
- Nenhum dado que permita identificar pessoas.
- Os códigos são material educativo e não substituem a leitura das notas técnicas de cada sistema de informação.
- As opiniões e análises são do autor e não representam instituições às quais ele esteja vinculado.
